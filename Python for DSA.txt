===============================
PYTHON FOR DSA ROADMAP
===============================

STEP 1 — LEARN PYTHON BASICS (1–2 WEEKS)
----------------------------------------

Learn:
- Variables
- Input / Output
- Data Types
- if / else
- for loop
- while loop
- Functions
- Lists
- Strings
- Dictionaries
- Sets
- Tuples

Practice:
- Reverse a string
- Find largest number
- Count vowels
- Palindrome check
- Fibonacci series

Example:
nums = [1, 2, 3]

for n in nums:
    print(n)


========================================

STEP 2 — LEARN PYTHON FEATURES FOR DSA
--------------------------------------

Learn:
- List slicing
- List comprehension
- sort() and sorted()
- Lambda functions
- collections module
- heapq
- deque
- Counter
- defaultdict

Example:
from collections import Counter

arr = [1,1,2,3,3,3]

print(Counter(arr))
